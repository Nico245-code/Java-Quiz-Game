# Java Quiz Game 🎮

Proyek permainan kuis sederhana berbasis Java untuk latihan pemrograman.

## Fitur
- Menu utama permainan
- Pertanyaan pilihan ganda
- Pemeriksaan jawaban
- Perhitungan skor pemain

## Teknologi
- Java
- Array
- Perulangan
- Class dan Object

## Cara Menjalankan

Pastikan Java JDK sudah terpasang.

Kompilasi program:

```bash
javac Main.java BankSoal.java Pemain.java
```

Jalankan program:

```bash
java Main
```

## Tujuan
Proyek latihan untuk memahami dasar-dasar pemrograman Java.
